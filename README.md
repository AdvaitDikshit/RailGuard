# RailGuard — Railway Track Crack Detection

Mini Project | MIT World Peace University, Pune  
Department of Mechanical Engineering | 2025-26

AI-based system for detecting cracks in railway tracks using YOLOv8.  
Built and trained from scratch on custom datasets from Roboflow.

## Tech Stack
- Python 3.10, Flask, YOLOv8 (Ultralytics)
- OpenCV, HTML5 / CSS3 / JavaScript
- Trained on merged Roboflow railway crack datasets

## Note
This is an academic project. Trained model weights and dataset  
are not included in this repository.
